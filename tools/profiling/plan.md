## System processes during measured blocks (decided before any G1 data)

- Measured blocks run with all user apps closed and the display asleep (`caffeinate -s` keeps the system awake, `pmset displaysleepnow`), started detached (`nohup`) so no agent or terminal process is busy.
- These macOS system processes are recorded in every manifest but do not flag a run below 50 % CPU: `WindowServer`, `kernel_task`, `mds`, `mds_stores`, `mdworker*`, `syspolicyd`, `airportd`. Above 50 % they flag it like any other process. Every other process keeps the 20 % rule.
- `ps` %CPU on macOS is a decaying average (about the last minute), not an instant reading; this is a stated limit of the rule (review O10).
- If more than a third of a block's runs are still flagged, the block is reported inconclusive; the list is not extended after seeing data. For G1b pass 2 this rule is overridden by D31 (post hoc, maintainer's decision). For G2 and G3 it is replaced by D34 and D38.
