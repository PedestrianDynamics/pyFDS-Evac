**This page reads tracked FDS output. You do not need to run FDS.**

The ASET-RSET comparison asks whether people can leave before conditions turn
untenable. Schröder, Arnold and Seyfried (2020) turned it from one number
into maps over the floor. `pyfds_evac.analysis` builds those maps from a
finished run and from FDS output:

- the **ASET map** is, for each map cell, the first time the fire makes it
  untenable;
- the **RSET map** is, for each cell, the last time anyone is in it;
- **DIFF = ASET − RSET**. Negative means the fire wins in that cell.

The module post-processes: it changes no simulation. It needs `pedpy>=1.5.1`
for the RSET map, which pyFDS-Evac now requires.

## A runnable example

The script is [`examples/aset_rset_maps.py`](https://github.com/PedestrianDynamics/pyFDS-Evac/blob/main/examples/aset_rset_maps.py).
Run it from the repository root (runtime about 10 s):

```bash
uv run python examples/aset_rset_maps.py
```

It takes the 10 × 10 m gas room of `assets/iso_table22_coupled` (deck e) and
20 people leaving through the corner exit in clear air. The gas of that deck
is uniform, so its ASET map is flat and only the RSET map varies; a real study
uses a fire that varies in space. The FED limit is 0.05 here so that the room
fails somewhere.

### ASET from the FDS output

`read_crossings` returns, for every node of the slices, the first time each
criterion is met, and the height of the slice it read.

```python
criteria = AsetCriteria(
    visibility_limit_m=None, temperature_c=None, heat_fed=None, fed=0.05
)
crossings = read_crossings(FDS, criteria)
for crossing in crossings:
    print(
        f"{crossing.name}: slice at z = {crossing.z_m} m, data to {crossing.horizon_s:.0f} s"
    )
```

### RSET from the runs

One run per seed. Passing `exit_times` lets the map tell an agent that left
from one still inside when the run ended.

```python
scenario = load_scenario("assets/iso_table22_coupled/config_a.json")
spawn = scenario.distributions["jps-distributions_0"]
spawn["coordinates"] = [[1, 1], [1, 5], [5, 5], [5, 1], [1, 1]]
spawn["parameters"].update(number=20, use_premovement=False)

rsets, grid = [], None
for seed in SEEDS:
    result = run_scenario(scenario, seed=seed)
    trajectory, walkable = load_trajectory(result.sqlite_file)
    grid = grid or grid_from_walkable(walkable, CELL)
    rsets.append(rset_map(trajectory, walkable, grid, exit_times=result.exit_times))
    print(
        f"seed {seed}: {len(result.exit_times)} left, remaining {result.agents_remaining}"
    )
    result.cleanup()
assert grid is not None
```

### DIFF, per seed and pooled

```python
aset = aset_map(grid, crossings)
per_seed = [measures(diff_map(aset, rset, grid)) for rset in rsets]
for name, interval in seed_measures(per_seed).items():
    print(
        f"{name}: mean {interval.mean:.2f}, 95 % CI {interval.low:.2f} to {interval.high:.2f}"
    )

pooled, pooled_values = pool_rset(rsets, "p95")
diff = diff_map(aset, pooled, grid)
m = measures(diff)
print(
    f"ASET {np.nanmin(aset.time_s):.0f} s everywhere on {int(grid.area.astype(bool).sum())} cells"
)
print(
    f"pooled RSET ({pooled_values.label}): last cell empty at {np.nanmax(pooled.time_s):.1f} s"
)
print(
    f"min DIFF {m.min_diff_s:.1f} s, failing area {m.fail_area_m2:.2f} m2, C {m.c_m2s:.1f} m2 s"
)
print(f"cells by state: { {k: v for k, v in m.counts.items() if v} }")
```

## The ASET criteria

A cell is untenable when **any** sample point in it meets a limit (the block
maximum, as the study chose). A point on a cell edge belongs to both cells.
`AsetCriteria` sets the limits; a `None` leaves a criterion out. The combined
ASET is the earliest crossing of any selected criterion, and every
criterion's own map is kept in `AsetMap.per_criterion`, under the name of
its crossing: `K 0.3` (the K limit), `T 45`, `FED 0.3` and `heat FED 0.3`,
with the limits you set. `AsetMap.deciding()` names, per cell, the criterion
that sets the ASET; criteria that tie are joined with `+` (`K 0.3+T 45`), and
cells without data or never untenable are empty. `plot_maps` draws it as a
fourth panel.

| Criterion | Per-point condition | Default | Source |
|---|---|---|---|
| Visibility | extinction coefficient K ≥ C / V<sub>lim</sub> | V<sub>lim</sub> = 10 m, C = 3, so K ≥ 0.3 1/m | 10 m: Engineers Australia (2014) p. 15, NZBC C/VM2 p. 30, vfdb TB 04-01 Table 8.3. C: Jin, as quoted in vfdb p. 314 and ISO 13571 Note 2 |
| Temperature | T ≥ T<sub>lim</sub> | 45 °C, stay under 30 min; 50 °C for about 15 min and under 5 min (`AsetCriteria.with_stay`) | vfdb TB 04-01 Table 8.3, DIN 18009-2 Table 1; dry air |
| Toxic FED | FED of a person standing still from t = 0 ≥ 0.3 | 0.3, configurable | ISO 13571 design criterion; the engine's own rate functions |
| Heat FED | convective heat FED, same person, ≥ 0.3 | 0.3, `clothed` law | ISO 13571:2012 Eq. 9 |

- Visibility and the limit are separate inputs. Schröder et al. use
  K ≥ 0.23 1/m (`extinction_per_m=0.23`, from the vfdb smoke density limit
  of 0.1 1/m) and 45 °C; the reproduction passes those.
- The study uses no FED criterion. The FED and heat FED maps **go beyond the
  paper**.
- The FED and heat FED maps are **location-only**: the dose of someone who
  stands at that point from t = 0, at the sampling height. It is not the dose
  of anyone's walk, which is what the per-agent summary of
  [the ASET check with FED](howto-aset-rset-check.md) gives.
- Dose criteria are integrated per sample point, with the engine's rule and
  clock (right endpoint, FED(t₀) = 0, one-second step, nearest slice frame),
  and the earliest point of a cell wins. A block-maximum concentration is
  never integrated.
- The slices are read at the engine's sampling height, 1.6 m by default;
  each result records the height of the slice it read.
- A cell that never meets a limit by the end of the fire data is **open**,
  not filled with the last time. A criterion with shorter data cuts the
  others at its horizon.
- A cell with no sample point or no floor has no data (NaN); it is never
  treated as safe.

The temperature limit assumes dry air, below 10 % water vapour by volume. The
maps do not read humidity.

## The RSET map and the five cell states

`rset_map` wraps PedPy's `compute_rset_map` with the maximum per cell. The
grid comes from PedPy's own output, row 0 at the largest y, so ASET and RSET
subtract with no flip; `tests/test_analysis_rset.py` fails if a PedPy release
changes its grid.

A cell's RSET is **censored** when it holds the last position of an agent that
never left (a time limit, a deadlock, an incapacitated agent). Pass the run's
`exit_times`; without them the cells of the last frame are censored and a
warning says so. From Python they are `ScenarioResult.exit_times`. A CLI run
keeps them in an `agent_exits` table of its `--output-sqlite` file;
`load_exit_times(sqlite_file)` reads it, and refuses a file without the table
rather than guessing exits from the last frame.

| State | ASET | RSET | DIFF |
|---|---|---|---|
| pass | exact | exact | ≥ 0 |
| fail | exact | exact | < 0 |
| ≥ bound | open (not by the end of the fire data) | exact | > T<sub>F</sub> − RSET |
| ≤ bound | exact | censored | < ASET − T<sub>R</sub> |
| undetermined | open | censored | none |

Cells with an ASET but nobody walked there cannot fail; cells with an RSET but
no ASET are a data gap. Both are counted and never passed.

## Measures, seeds

`measures` gives, on the cells where DIFF is exact: the minimum DIFF and its
cell, the failing area in m² (true floor area per cell), and **C**, the sum
of DIFF times area over the failing cells in m² s, without binning. The
paper's C bins DIFF into 20 s classes; `Measures.c_binned_m2s` and
`release_measures` give that only to compare with the paper. `support`
is `"intersection"` (cells with both maps) or `"union"`; the failing area and
C are the same, the shares and the coverage report differ.

One run per seed gives one RSET map. `pool_rset` takes the 95th percentile per
cell over the seeds that visit it, and a cell censored in any seed stays
censored. `seed_measures` gives each measure per seed with a 95 % bootstrap
interval of the mean, and `convergence_curve` the interval half-width against
the number of seeds. Choose the number of seeds from the curve. A maximum over
seeds grows with their number; `pool_seeds(..., "max")` carries it as
`"max over n=…"`.

## Sign visibility is a different map

Whether the signs of a route can be read through the smoke is a wayfinding
question. It is not a tenability limit and is not part of DIFF. fdsvismap
computes it separately
([#140](https://github.com/PedestrianDynamics/pyFDS-Evac/issues/140)).

## Verification against the data release

Run with `SCHROEDER2020_RELEASE` set to the unpacked Zenodo release
(`tests/test_analysis_zenodo.py`; the release is not in the repository).

- **Stage 1, exact.** The released difference map, counted by the release's
  rules: min DIFF −29 s, 54 cells (19.44 m²) with DIFF ≤ 0, C = −310 m² s
  binned. By the default rules (DIFF = 0 passes, bin-free C): 52 cells,
  C = −274.7 m² s.
- **Stage 2, rebuild.** ASET and RSET rebuilt with this module (PedPy RSET)
  against row A of `scripts/docs/schroeder2020_reproduce.py`: min DIFF
  differs by 2 s and the failing area by −9 %, within the predeclared 10 s
  and 10 %.
- Only the `nearest` cell rule is checked against the release. The default
  `exists` rule (block maximum) has no release check.

## Limits

- The FED and heat FED maps are for a person standing still from t = 0; they
  are conservative and not a walker's dose.
- ASET is read on one slice height. The cell rules `exists`, `all` and
  `nearest` are available (`cell_rule`); the cell-centre rule of the study
  script is not.
- The ASET is as fine as the slice output interval for the level criteria
  (visibility, temperature), and one second for the dose criteria.
- RSET here is travel and modelled pre-movement from ignition. Detection and
  alarm times are not included (ISO/TR 16738).
- With few seeds the 95th percentile lies near the maximum.
- Research software. No result is a design or safety verdict.
