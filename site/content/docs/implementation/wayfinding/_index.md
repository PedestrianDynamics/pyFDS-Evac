The wayfinding model is
described in [Visibility and cognitive maps](/models/visibility.md): sign
legibility through smoke, and the per-agent cognitive map it feeds. The ideas
behind it, with figures, are in the
[Wayfinding section of Concepts](/docs/concepts.md#wayfinding). The
[familiarity routing verification](/models/verification/testing-familiarity.md)
checks that fully familiar and discovering agents behave differently.
